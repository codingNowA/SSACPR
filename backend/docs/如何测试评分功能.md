# 如何测试简历评分功能

## 功能说明

简历评分功能会对上传的简历进行多维度评分，包括：

1. **完整性评分 (25%)**：评估简历信息是否完整（基本信息、教育经历、工作经历、项目经验、技能标签）
2. **专业性评分 (20%)**：评估语言质量、格式一致性、细节丰富度
3. **量化程度评分 (20%)**：评估成果描述中的量化数据使用情况
4. **项目深度评分 (20%)**：评估项目经验的数量、技术栈、成果描述
5. **岗位匹配评分 (15%，可选)**：评估与目标岗位的匹配度（需提供岗位信息）

## 测试步骤

### 方法 1：使用 Swagger UI（推荐）

1. **启动后端服务**
   ```bash
   cd backend
   uvicorn app.main:app --reload
   ```

2. **打开 Swagger UI**
   - 浏览器访问：http://localhost:8000/docs
   - 找到 `/api/v1/resume/score` 接口

3. **上传简历并评分**
   - 点击 "Try it out"
   - 选择简历文件（PDF、DOCX 或图片）
   - （可选）填写 `job_title`：目标岗位名称，如 "Python 后端工程师"
   - （可选）填写 `job_description`：岗位描述
   - 点击 "Execute"

4. **查看评分结果**

### 方法 2：使用 curl 命令

```bash
# 基础评分（不含岗位匹配）
curl -X POST "http://localhost:8000/api/v1/resume/score" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@/path/to/your/resume.pdf"

# 带岗位匹配的评分
curl -X POST "http://localhost:8000/api/v1/resume/score?job_title=Python%E5%90%8E%E7%AB%AF%E5%B7%A5%E7%A8%8B%E5%B8%88" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@/path/to/your/resume.pdf"
```

### 方法 3：使用 Python 脚本

```python
import requests

url = "http://localhost:8000/api/v1/resume/score"

# 准备文件
files = {
    'file': open('your_resume.pdf', 'rb')
}

# 可选参数
params = {
    'job_title': 'Python 后端工程师',
    'job_description': '负责后端系统开发，熟悉 Python、FastAPI、PostgreSQL'
}

# 发送请求
response = requests.post(url, files=files, params=params)
print(response.json())
```

## 评分标准说明

### 完整性评分（满分 100）
- 基本信息存在：20 分
  - 姓名：+5 分
  - 电话：+5 分
  - 邮箱：+5 分
- 教育经历：20 分
- 工作经历：20 分
- 项目经验：15 分
- 技能标签：10 分

### 专业性评分（满分 100）
- 语言质量：基础 70 分，根据文本长度和质量加分
- 格式一致性：基础 70 分，日期格式统一最多 +30 分
- 细节丰富度：基础 50 分，根据描述长度和数量加分

### 量化程度评分（满分 100）
- 计算公式：(量化成果数 / 总成果数) × 100
- 判断标准：包含数字、百分比、倍数等量化指标

### 项目深度评分（满分 100）
- 项目数量：最多 30 分
- 技术栈丰富度：最多 30 分
- 成果描述：最多 20 分
- 详细描述：20 分

### 岗位匹配评分（满分 100，可选）
- 技能匹配：50%
- 经验匹配：30%
- 学历匹配：20%

## 测试建议

1. **准备不同质量的简历**：
   - 完整简历（包含所有模块）
   - 不完整简历（缺少某些模块）
   - 量化清晰的简历（成果描述有数据）
   - 量化不足的简历（描述模糊）

2. **测试岗位匹配**：
   - 提供目标岗位和技能要求
   - 观察匹配度评分和建议

3. **观察评分结果**：
   - 总分是否合理
   - 各维度得分是否准确
   - 反馈建议是否有帮助

## 常见问题

### Q: 评分需要多长时间？
A: 通常 5-15 秒，取决于简历长度和 LLM 响应速度。

### Q: 支持哪些文件格式？
A: 支持 PDF、DOCX、PNG、JPG、JPEG。

### Q: 岗位匹配评分是必需的吗？
A: 不是，可以不提供岗位信息，系统会跳过岗位匹配评分。

### Q: 评分标准可以调整吗？
A: 可以，在 `backend/app/core/resume/scorer.py` 中修改 `WEIGHTS` 配置和评分逻辑。
