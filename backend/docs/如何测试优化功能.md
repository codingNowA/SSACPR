# 如何测试简历优化功能

## 功能说明

简历优化功能会对上传的简历生成：

1. **通用优化建议**：基于评分结果生成的可执行修改建议
   - 完整性建议（补充缺失信息）
   - 专业性建议（统一格式、丰富细节）
   - 量化程度建议（增加数据支撑）
   - 项目深度建议（丰富项目描述）

2. **面向岗位的优化文案**（可选）：
   - 岗位关键要求分析
   - 简历已匹配优势
   - 需要改进的方面
   - 针对岗位优化的各章节文案
   - 额外优化建议

3. **优先行动清单**：最重要的改进事项

4. **预估改进效果**：优化后各维度的预期提升

## 测试步骤

### 方法 1：使用 Swagger UI（推荐）

1. **启动后端服务**
   ```bash
   cd backend
   uvicorn app.main:app --reload
   ```

2. **打开 Swagger UI**
   - 浏览器访问：http://localhost:8000/docs
   - 找到 `/api/v1/resume/optimize` 接口

3. **测试通用优化（不含岗位信息）**
   - 点击 "Try it out"
   - 选择简历文件（PDF、DOCX 或图片）
   - 不填写 `job_title` 和 `job_description`
   - 点击 "Execute"
   - 查看返回的通用优化建议

4. **测试岗位优化（含岗位信息）**
   - 点击 "Try it out"
   - 选择简历文件
   - 填写 `job_title`：如 "Python 后端工程师"
   - （可选）填写 `job_description`：如 "负责后端系统开发，要求熟悉 Python、FastAPI、PostgreSQL、Redis，有微服务经验优先"
   - 点击 "Execute"
   - 查看返回的通用建议 + 岗位优化文案

### 方法 3：使用 Python 脚本

```python
import requests

url = "http://localhost:8000/api/v1/resume/optimize"

# 准备文件
files = {
    'file': open('your_resume.pdf', 'rb')
}

# 可选参数
params = {
    'job_title': 'Python 后端工程师',
    'job_description': '负责后端系统开发，熟悉 Python、FastAPI、PostgreSQL'
}

# 发送请求
response = requests.post(url, files=files, params=params)
result = response.json()

# 打印结果
print("优化建议：")
for suggestion in result['data']['optimization']['general_suggestions']:
    print(f"\n【{suggestion['priority']}】{suggestion['title']}")
    print(f"  问题：{suggestion['description']}")
    print(f"  建议：{suggestion['suggested_content']}")
    print(f"  原因：{suggestion['reason']}")

if result['data']['optimization']['job_targeted']:
    print("\n\n岗位优化：")
    job_opt = result['data']['optimization']['job_targeted']
    print(f"目标岗位：{job_opt['job_title']}")
    print(f"匹配度：{job_opt['match_score']}")
    print(f"已匹配优势：{', '.join(job_opt['matched_points'])}")
    print(f"需要改进：{', '.join(job_opt['improvement_areas'])}")
```

## 功能特点

### 1. 通用优化建议

- **自动检测问题**：基于评分结果自动识别简历的不足
- **可执行建议**：每条建议都包含当前内容和建议修改内容
- **优先级排序**：高、中、低三级，帮助用户优先处理重要问题
- **示例提供**：部分建议提供具体示例，方便用户参考

### 2. 岗位优化文案

- **需求分析**：提取岗位的关键要求
- **优势识别**：指出简历中已匹配的优势
- **差距分析**：明确需要改进的方面
- **定向优化**：为关键章节生成优化后的文案
- **改进说明**：详细说明每处优化的改进点

### 3. 智能特性

- **LLM 驱动**：使用大语言模型理解岗位要求和简历内容
- **上下文感知**：优化建议考虑简历整体情况
- **真实性原则**：优化文案基于现有内容，不夸大不捏造
- **可解释性**：每条建议都说明原因和改进效果

## 测试建议

1. **准备不同质量的简历**：
   - 完整简历 vs 不完整简历
   - 量化清晰 vs 量化不足
   - 详细描述 vs 简单描述

2. **测试不同岗位**：
   - 技术岗位（Python 开发、前端工程师等）
   - 不同行业（互联网、金融、教育等）
   - 不同级别（初级、中级、高级）

3. **观察优化效果**：
   - 建议是否针对性强
   - 优化文案是否自然
   - 改进效果预估是否合理

## 常见问题

### Q: 优化需要多长时间？
A: 通用优化约 5-10 秒，岗位优化约 10-20 秒（需要调用 LLM）。

### Q: 优化建议的数量？
A: 通用建议最多 10 条，按优先级排序。岗位优化的章节数量根据实际情况而定。

### Q: 是否支持指定优化重点？
A: 当前版本自动识别重点，未来版本将支持 `focus_areas` 参数指定关注领域。

### Q: 优化文案是否可以直接使用？
A: 优化文案基于现有内容生成，可以作为参考，但建议根据实际情况调整。

### Q: 如何调整优化策略？
A: 可以在 `backend/app/core/resume/optimizer.py` 中调整优化逻辑和 LLM prompt。

```

    ↓

    ↓

    ↓
返回优化结果
```
