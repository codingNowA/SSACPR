# 如何测试简历解析功能

## 📋 准备工作

1. **确保服务正在运行**
   ```bash
   cd backend
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

2. **准备测试文件**
   - 准备你自己的简历文件（PDF、Word 或图片格式）
   - 建议文件大小 < 10MB

---

## 🧪 测试方法

### 方法 1: 使用 Swagger UI（推荐，最简单）

1. **打开浏览器，访问**
   ```
   http://localhost:8000/docs
   ```

2. **测试支持的格式**
   - 找到 `GET /api/v1/resume/formats`
   - 点击 "Try it out"
   - 点击 "Execute"
   - 查看支持的文件格式

3. **测试解析功能**
   - 找到 `POST /api/v1/resume/parse`
   - 点击 "Try it out"
   - 点击 "Choose File" 上传你的简历
   - 点击 "Execute"
   - 查看解析结果

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "text": "你的简历文本内容...",
    "file_type": "pdf",
    "file_path": "uploads/resumes/xxx.pdf",
    "word_count": 1234,
    "char_count": 5678,
    "page_count": 2
  }
}
```

---

### 方法 2: 使用 curl 命令

**查看支持的格式**：
```bash
curl http://localhost:8000/api/v1/resume/formats | python -m json.tool
```

**上传并解析简历**：
```bash
# 替换 /path/to/your/resume.pdf 为你的简历路径
curl -X POST http://localhost:8000/api/v1/resume/parse \
  -F "file=@/path/to/your/resume.pdf" \
  | python -m json.tool
```

**示例**：
```bash
# Windows 路径示例
curl -X POST http://localhost:8000/api/v1/resume/parse \
  -F "file=@D:/Documents/my_resume.pdf" \
  | python -m json.tool

# 相对路径示例
curl -X POST http://localhost:8000/api/v1/resume/parse \
  -F "file=@./my_resume.docx" \
  | python -m json.tool
```

---

### 方法 3: 使用 Python 代码

```python
import requests

# 上传并解析
with open('your_resume.pdf', 'rb') as f:
    files = {'file': ('resume.pdf', f, 'application/pdf')}
    response = requests.post(
        'http://localhost:8000/api/v1/resume/parse',
        files=files
    )

result = response.json()
print(f"提取的文本: {result['data']['text'][:200]}...")
print(f"字数: {result['data']['word_count']}")
print(f"字符数: {result['data']['char_count']}")
```

## 📝 支持的文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 支持文本 PDF（扫描件需要 OCR） |
| Word | `.docx` | 仅支持 .docx，不支持旧版 .doc |
| 图片 | `.png`, `.jpg`, `.jpeg` | 需要安装 Tesseract OCR |

**文件大小限制**: 10MB

---

## 🔧 如果要测试图片格式

图片格式需要 OCR 支持，需要安装 Tesseract：

### Windows
1. 下载安装包: https://github.com/UB-Mannheim/tesseract/wiki
2. 运行安装程序
3. （可选）配置 `.env` 文件：
   ```
   TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
   OCR_LANG=chi_sim+eng
   ```

### Linux
```bash
sudo apt-get install tesseract-ocr tesseract-ocr-chi-sim
```

### macOS
```bash
brew install tesseract tesseract-lang
```

## ❓ 常见问题

### Q: 上传文件失败？
**A**: 检查文件格式和大小
- 确保文件格式在支持列表中
- 确保文件小于 10MB

### Q: PDF 解析不出内容？
**A**: 检查 PDF 类型
- 如果是扫描件 PDF，需要使用图片格式 + OCR
- 尝试在 PDF 阅读器中复制文本，如果能复制说明是文本 PDF

### Q: Word 文件不支持？
**A**: 确保是 .docx 格式
- 旧版 .doc 不支持
- 可以用 Word 另存为 .docx 格式

### Q: API 连接失败？
**A**: 确保服务已启动
```bash
uvicorn main:app --reload
```
