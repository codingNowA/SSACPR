# 如何测试简历结构化提取功能

## ⚠️ 前置要求

### 1. 配置 LLM（必需）

在 `backend/.env` 文件中配置 LLM：

```bash
# LLM 配置
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=your_api_key_here
LLM_MODEL=gpt-4
LLM_TEMPERATURE=0.1
```

**如果没有配置 LLM，提取功能将无法使用！**

### 2. 启动服务

```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

---

## 🧪 测试方法

### 方法 1: Swagger UI（推荐）

1. **打开浏览器**
   ```
   http://localhost:8000/docs
   ```

2. **找到新接口**
   - 查找 `POST /api/v1/resume/extract`
   - 这是结构化提取接口

3. **测试步骤**
   - 点击 "Try it out"
   - 点击 "Choose File" 上传你的简历（PDF/Word）
   - 点击 "Execute"
   - 查看提取的结构化数据

4. **查看结果**
   响应包含：
   - `text`: 原始简历文本
   - `structured_data`: 结构化信息
     - `basic_info`: 基本信息（姓名、电话、邮箱等）
     - `education`: 教育经历数组
     - `work_experience`: 工作/实习经历数组
     - `project_experience`: 项目经验数组
     - `skills`: 技能标签数组

### 方法 3: Python 代码测试

```python
import requests
import json

# 上传并提取
with open('your_resume.pdf', 'rb') as f:
    files = {'file': ('resume.pdf', f, 'application/pdf')}
    response = requests.post(
        'http://localhost:8000/api/v1/resume/extract',
        files=files
    )

result = response.json()

# 打印结构化数据
data = result['data']['structured_data']

print("=== 基本信息 ===")
basic = data['basic_info']
print(f"姓名: {basic.get('name')}")
print(f"电话: {basic.get('phone')}")
print(f"邮箱: {basic.get('email')}")
print(f"求职意向: {basic.get('job_intention')}")

print("\n=== 教育经历 ===")
for edu in data['education']:
    print(f"• {edu['school']} - {edu['major']} ({edu['degree']})")
    print(f"  时间: {edu.get('start_date')} ~ {edu.get('end_date')}")

print("\n=== 工作经历 ===")
for work in data['work_experience']:
    print(f"• {work['company']} - {work['position']}")
    print(f"  时间: {work.get('start_date')} ~ {work.get('end_date')}")
    if work.get('achievements'):
        print(f"  成果: {', '.join(work['achievements'][:2])}")

print("\n=== 项目经验 ===")
for proj in data['project_experience']:
    print(f"• {proj['name']} - {proj.get('role')}")
    if proj.get('tech_stack'):
        print(f"  技术栈: {', '.join(proj['tech_stack'])}")

print("\n=== 技能标签 ===")
for skill in data['skills']:
    print(f"• {skill['name']} ({skill.get('category')}) - {skill.get('level')}")
```

## ❓ 常见问题

### Q1: 提示 "LLM 配置不完整"
**原因**: 没有配置 `.env` 文件中的 LLM 设置

**解决**: 
1. 在 `backend/.env` 中添加：
   ```bash
   LLM_BASE_URL=https://api.openai.com/v1
   LLM_API_KEY=your_api_key
   LLM_MODEL=gpt-4
   ```
2. 重启服务

---

### Q2: 提取结果不准确
**可能原因**: 
- 简历格式不规范
- 文本提取质量差（扫描件 PDF）
- LLM 模型能力不足

**建议**: 
- 使用文本 PDF，避免扫描件
- 使用更强大的 LLM 模型（如 GPT-4）
- 确保简历格式清晰规范

---

### Q3: 处理时间过长
**原因**: LLM 调用需要时间（2-10 秒）

**正常**: 
- 简单简历: 2-5 秒
- 复杂简历: 5-10 秒

**优化**: 
- 使用更快的 LLM 模型
- 考虑添加缓存机制

---

### Q4: 某些字段为空
**原因**: 简历中没有相关信息

**正常行为**: 
- 如果简历没有某项信息，该字段为 `null` 或空数组
- 这是预期行为，不是错误
