## 🚀 如何使用

### 启动服务

```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 访问 API 文档

浏览器打开: http://localhost:8000/docs

### Python 使用示例

```python
import requests

# 解析 PDF 简历
with open('resume.pdf', 'rb') as f:
    response = requests.post(
        'http://localhost:8000/api/v1/resume/parse',
        files={'file': f}
    )
    result = response.json()
    
    if result['code'] == 200:
        data = result['data']
        print(f"✅ 解析成功")
        print(f"字数: {data['word_count']}")
        print(f"页数: {data['page_count']}")
        print(f"预览: {data['text'][:200]}...")
```

### cURL 使用示例

```bash
# 上传简历
curl -X POST "http://localhost:8000/api/v1/resume/upload" \
  -F "file=@resume.pdf"

# 解析简历
curl -X POST "http://localhost:8000/api/v1/resume/parse" \
  -F "file=@resume.pdf"

# 查询支持格式
curl "http://localhost:8000/api/v1/resume/formats"
```

## ⚠️ 注意事项

1. **Word 格式限制**: 仅支持 `.docx`，不支持旧的 `.doc` 格式
2. **图片 OCR**: 需要安装 Tesseract OCR，否则无法解析图片
3. **文件大小**: 默认限制 10MB
4. **PDF 加密**: 加密的 PDF 无法解析
