# 简历结构化提取功能文档

## 功能概述

从简历文本中自动提取结构化信息，包括：
- 基本信息（姓名、电话、邮箱、年龄、性别、所在地、求职意向）
- 教育经历（学校、专业、学历、时间、GPA）
- 工作/实习经历（公司、职位、时间、工作内容、成果）
- 项目经验（项目名称、角色、时间、描述、技术栈、成果）
- 技能标签（分类、名称、熟练度）

---

**请求**：
- Method: `POST`
- Content-Type: `multipart/form-data`

## 数据结构

### BasicInfo - 基本信息
```python
{
    "name": str,              # 姓名
    "phone": str,             # 电话
    "email": str,             # 邮箱
    "age": int,               # 年龄
    "gender": str,            # 性别
    "location": str,          # 所在地
    "job_intention": str      # 求职意向
}
```

### Education - 教育经历
```python
{
    "school": str,            # 学校名称
    "major": str,             # 专业
    "degree": str,            # 学历（本科/硕士/博士）
    "start_date": str,        # 开始时间
    "end_date": str,          # 结束时间
    "gpa": str,               # GPA
    "description": str        # 描述
}
```

### WorkExperience - 工作/实习经历
```python
{
    "company": str,           # 公司名称
    "position": str,          # 职位
    "start_date": str,        # 开始时间
    "end_date": str,          # 结束时间
    "description": str,       # 工作内容描述
    "achievements": [str]     # 工作成果列表
}
```

### ProjectExperience - 项目经验
```python
{
    "name": str,              # 项目名称
    "role": str,              # 项目角色
    "start_date": str,        # 开始时间
    "end_date": str,          # 结束时间
    "description": str,       # 项目描述
    "tech_stack": [str],      # 技术栈列表
    "achievements": [str]     # 项目成果列表
}
```

### SkillTag - 技能标签
```python
{
    "category": str,          # 技能分类（编程语言/框架/工具等）
    "name": str,              # 技能名称
    "level": str              # 熟练度（熟练/精通/了解）
}
```

## 使用方法

### 方法 1: Swagger UI

1. 启动服务：
   ```bash
   uvicorn main:app --reload
   ```

2. 访问：http://localhost:8000/docs

3. 找到 `POST /api/v1/resume/extract` 接口

4. 点击 "Try it out"，上传简历文件

5. 点击 "Execute"，查看提取结果

---

### 方法 2: curl 命令

```bash
curl -X POST http://localhost:8000/api/v1/resume/extract \
  -F "file=@your_resume.pdf" \
  | python -m json.tool
```

---

### 方法 3: Python 代码

```python
import requests

with open('resume.pdf', 'rb') as f:
    files = {'file': ('resume.pdf', f, 'application/pdf')}
    response = requests.post(
        'http://localhost:8000/api/v1/resume/extract',
        files=files
    )

result = response.json()
data = result['data']

# 访问基本信息
print(f"姓名: {data['structured_data']['basic_info']['name']}")
print(f"电话: {data['structured_data']['basic_info']['phone']}")

# 访问教育经历
for edu in data['structured_data']['education']:
    print(f"学校: {edu['school']}")
    print(f"专业: {edu['major']}")

# 访问工作经历
for work in data['structured_data']['work_experience']:
    print(f"公司: {work['company']}")
    print(f"职位: {work['position']}")

# 访问项目经验
for project in data['structured_data']['project_experience']:
    print(f"项目: {project['name']}")
    print(f"技术栈: {', '.join(project['tech_stack'])}")

# 访问技能标签
for skill in data['structured_data']['skills']:
    print(f"{skill['category']}: {skill['name']} ({skill['level']})")
```

## 技术实现

### 1. 文本提取
使用 [ResumeParser](app/core/resume/parser.py) 从各种格式提取文本：
- PDF: PyPDF2
- Word: python-docx
- 图片: pytesseract (OCR)

### 2. 结构化提取
使用 [ResumeExtractor](app/core/resume/extractor.py) + LLM 提取结构化信息：
- 使用精心设计的 prompt 指导 LLM
- 温度设置为 0.1 确保输出稳定
- 返回标准 JSON 格式
- Pydantic 模型验证数据

### 3. 数据验证
使用 Pydantic 模型确保数据类型正确：
- 自动类型转换
- 字段验证
- 默认值处理
- 可选字段支持

## 配置要求

### 环境变量

在 `.env` 文件中配置：

```bash
# LLM 配置（必需）
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=your_api_key_here
LLM_MODEL=gpt-4
LLM_TEMPERATURE=0.1

# 可选：调试模式
LLM_DRY_RUN=false
```

---

## 注意事项

1. **LLM 必需**: 结构化提取功能需要配置 LLM（如 OpenAI GPT-4 或兼容的本地模型）

2. **提取准确性**: 
   - 准确性取决于简历文本质量和 LLM 能力
   - 建议使用文本 PDF，扫描件需要 OCR 可能影响准确性

3. **处理时间**: 
   - LLM 调用需要 2-10 秒
   - 文件越大，处理时间越长

4. **成本考虑**: 
   - 每次提取会调用 LLM API
   - 建议使用缓存避免重复提取

## 错误处理

### 常见错误

1. **LLM 配置不完整**
   ```json
   {
     "detail": "结构化提取失败: LLM 配置不完整，请检查 LLM_BASE_URL 和 LLM_API_KEY"
   }
   ```
   **解决**: 配置 `.env` 文件中的 LLM 设置

2. **文本提取失败**
   ```json
   {
     "detail": "文本提取失败: 提取的文本内容过少"
   }
   ```
   **解决**: 检查文件是否损坏或为空

3. **LLM 调用失败**
   ```json
   {
     "detail": "结构化提取失败: LLM 调用失败"
   }
   ```
   **解决**: 检查网络连接和 API Key
