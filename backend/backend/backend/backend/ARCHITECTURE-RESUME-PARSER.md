## 数据模型关系

```
┌─────────────────────────┐
│   ApiResponse[T]        │  泛型响应包装器
│  ───────────────────    │
│  + code: int            │
│  + message: str         │
│  + data: T              │
└───────────┬─────────────┘
            │
            │ 包装
            ▼
┌─────────────────────────┐
│ ResumeParseResponse     │  解析响应数据
│ ─────────────────────   │
│ + text: str             │  提取的文本
│ + file_type: str        │  文件类型
│ + file_path: str        │  文件路径
│ + page_count: int?      │  页数
│ + word_count: int       │  字数
│ + char_count: int       │  字符数
└─────────────────────────┘

┌─────────────────────────┐
│ ResumeUploadResponse    │  上传响应数据
│ ─────────────────────   │
│ + file_path: str        │  文件路径
│ + file_type: str        │  文件类型
│ + message: str          │  响应消息
└─────────────────────────┘

┌─────────────────────────┐
│ ResumeParseRequest      │  解析请求数据
│ ─────────────────────   │
│ + file_path: str        │  文件路径
│ + file_type: str?       │  文件类型(可选)
└─────────────────────────┘
```

## 错误处理流程

```
异常类型                         处理方式                    HTTP 状态码
    │                               │                           │
    ▼                               ▼                           ▼
FileHandlerError  ────────▶  文件处理错误提示  ────────▶  400 Bad Request
    │                               │
    │  • 文件类型不支持             │
    │  • 文件大小超限               │
    │  • 文件保存失败               │
    │                               │
ResumeParserError ────────▶  解析错误提示      ────────▶  400 Bad Request
    │                               │
    │  • PDF 解析失败               │
    │  • Word 解析失败              │
    │  • OCR 识别失败               │
    │                               │
OCRError          ────────▶  OCR 错误提示      ────────▶  400 Bad Request
    │                               │
    │  • Tesseract 未安装           │
    │  • 图片格式错误               │
    │                               │
Exception         ────────▶  通用错误提示      ────────▶  500 Internal Server Error
```
