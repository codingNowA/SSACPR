## ⚠️ 注意事项

1. **Word 格式限制**: 仅支持 `.docx`，不支持旧的 `.doc` 格式
2. **图片 OCR**: 需要安装 Tesseract OCR，否则无法解析图片格式
3. **文件大小**: 默认限制 10MB，可通过环境变量 `MAX_UPLOAD_SIZE` 配置
4. **PDF 限制**: 加密或受保护的 PDF 无法解析
5. **扫描版 PDF**: 如果 PDF 是扫描件，需要 OCR 处理（待优化）
