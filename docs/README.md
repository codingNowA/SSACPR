# 项目文档目录

本目录包含 SSACPR 项目的所有文档。

## 📁 目录结构

```
docs/
├── README.md                    # 本文件
├── PROJECT_SUMMARY.md           # 项目概述
├── architecture/                # 架构设计文档
│   └── ARCHITECTURE.md          # 系统架构说明
├── development/                 # 开发相关文档
│   ├── SETUP.md                 # 开发环境搭建指南
│   ├── REQUIREMENTS.md          # 需求文档
│   ├── FEATURE_CHECKLIST.md     # 功能清单
│   └── TROUBLESHOOTING.md       # 常见问题排查指南
├── guides/                      # 使用指南
│   └── JWT认证使用指南.md       # JWT 认证使用教程
└── reports/                     # 测试报告
    └── 测试报告.md              # 系统功能测试报告
```

## 📖 文档说明

### 架构文档
- **ARCHITECTURE.md**: 系统整体架构设计、技术栈选型、模块划分

### 开发文档
- **SETUP.md**: 本地开发环境搭建步骤
- **REQUIREMENTS.md**: 功能需求和技术需求说明
- **FEATURE_CHECKLIST.md**: 功能开发进度清单

### 使用指南
- **JWT认证使用指南.md**: JWT 认证机制详细说明和 Swagger UI 使用教程

### 测试报告
- **测试报告.md**: 系统功能测试结果和验证报告

## 🚀 快速开始

1. 首次使用，请阅读：[../README.md](../README.md)
2. 搭建开发环境：[development/SETUP.md](development/SETUP.md)
3. 了解 JWT 认证：[guides/JWT认证使用指南.md](guides/JWT认证使用指南.md)
4. 查看测试结果：[reports/测试报告.md](reports/测试报告.md)

## 📝 文档更新

文档应随项目开发同步更新。如有问题或建议，请提 Issue。
