## ✨ 核心功能

### 1. 通用优化建议

基于简历评分，自动生成 4 大类优化建议：

- **完整性建议**：补充缺失的信息模块
- **专业性建议**：统一格式、丰富细节（LLM 辅助）
- **量化程度建议**：增加数据支撑
- **项目深度建议**：丰富项目描述

每条建议包含：
- 问题描述
- 当前内容
- 建议修改内容
- 修改原因
- 具体示例

### 2. 面向岗位的优化文案

针对目标岗位，使用 LLM 生成：

- 岗位关键要求分析
- 简历已匹配的优势
- 需要改进的方面
- 关键章节的优化文案（对比展示）
- 改进点详细说明

### 3. 辅助功能

- **优先行动清单**：提取高优先级建议，帮助用户快速定位
- **改进效果预估**：预测优化后各维度的分数提升
- **优化总结**：一句话概括优化方向和预期效果

---

## 🔧 技术亮点

### 1. 智能降级策略
- LLM 失败时自动切换到规则生成
- 保证功能可用性 100%
- 不影响用户体验

### 2. 混合方法
- 规则驱动：完整性、量化、项目深度（快速、稳定）
- LLM 辅助：专业性、岗位优化（智能、灵活）
- 优势互补，效果最优

### 3. 结构化输出
- Pydantic 数据模型保证类型安全
- 规范的 JSON 格式
- 便于前端展示和处理

### 4. 可扩展性
- 模块化设计，易于添加新的优化维度
- 支持自定义优化策略
- 便于维护和升级

```bash

curl -X POST "http://localhost:8000/api/v1/resume/optimize" \
  -F "file=@resume.pdf"

# 岗位优化
curl -X POST "http://localhost:8000/api/v1/resume/optimize" \
  -F "file=@resume.pdf" \
  -d "job_title=Python后端工程师" \
```
